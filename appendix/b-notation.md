# 附录 B 符号表

本表是全书符号的唯一权威来源。写作与阅读时若发现符号冲突，以本表为准；新增符号会在每章末尾的增量清单中登记。

## B.0 排版约定

| 约定 | 含义 | 示例 |
| --- | --- | --- |
| 粗体大写 | 矩阵 | $$\mathbf{W}$$、$$\mathbf{Q}$$ |
| 粗体小写 | 向量 | $$\mathbf{x}$$、$$\mathbf{h}$$ |
| 普通斜体 | 标量 | $$d_{model}$$、$$\alpha$$ |
| 下标 $$t$$ | 序列位置 | $$\mathbf{x}_t$$ |
| 下标 $$i, j$$ | 索引 | $$s_{ij}$$ |
| 上标 $$(l)$$ | 第 $$l$$ 层 | $$\mathbf{X}^{(l)}$$ |
| $$\odot$$ | 逐元素乘 | $$\mathbf{a} \odot \mathbf{b}$$ |
| $$[\cdot]$$ | 向量拼接 | $$[\mathbf{a}; \mathbf{b}]$$ |

{% hint style="warning" %}
少数希腊字母在不同语境下复用，靠上下文或下标区分：$$\gamma$$ 在归一化中指**增益向量**（加粗），在强化学习中指**折扣因子**（标量）；$$\beta$$ 在 Adam 中指动量系数（带下标），在 DPO 中指偏好温度（不带下标）；$$k$$ 在 MoE 与 Top-k 采样中指"取前 k 个"，在 n-gram 中指加性平滑常数；$$\epsilon$$ 在归一化中是数值稳定项，在 PPO 中是裁剪系数（带下标 $$clip$$）。

同一字母在不同章节的区分规则：$$n_{vocab}$$ 始终表示词表大小，词表集合用 $$\mathcal{V}$$，注意力的值矩阵是粗体 $$\mathbf{V}$$；$$B$$ 是批大小，文本字节数用 $$B_{\text{byte}}$$；$$C$$ 是训练算力，字符数用 $$n_{\text{char}}$$；$$W$$ 是滑动窗口大小，词数用 $$n_{\text{word}}$$；$$M_{ij}$$ 是因果掩码，$$M$$ 是 BPE 合并次数；$$z_t$$ 是 Token ID，BPE 的符号序列用 $$q$$，Unigram 的 Token 用 $$u$$；上标 $$(h)$$ 表示第 $$h$$ 个注意力头；$$\mathbf{h}_t$$ 无上标时指循环网络的隐状态，带上标 $$\mathbf{h}_t^{(l)}$$ 时指第 $$l$$ 层残差流在位置 $$t$$ 的表示。
{% endhint %}
